# 🎯 JS-ATGM
### Air-to-Ground Guided Weapons for FiveM

**Targeting pod · Laser designation · Guided missiles & bombs**

Sit in the gunner seat of an Apache, press **B**, and look through a real **TADS / LITENING-style targeting pod** — gray TV by day, **thermal** at night, a coded laser on the target.
Mark up to 8 targets, release, and every weapon flies to its own target while you are already looking at the next one.

## ✨ Features
- 🎥 **Real pod camera** — zoom, gimbal limits, stabilisation, gray TV (DTV) and thermal (IR)
- 🔴 **Laser designator** with codes + **buddy lasing** (the helicopter lases, the jet drops)
- 🎯 **Multi-target** — mark T1–T8, one click = one weapon on each
- 🔄 **Redirect in flight** — move the point, the weapon follows
- 🚀 **Real physics** — missiles and bombs seen by the whole server
- 📡 **Far targets** — real players up to 1.5 km in full detail, beyond that as heat spots
- 💣 **Release envelope** — warns when a bomb may fall short
- 🛫 **Add-on ready** — AH-64, F-16I, F-15I, F-35I in one config line
- 🧩 **Works with JS-AirHUD** — the jet HUD steps aside while the pod is open
- 🛡️ **Server-side security** — ammo, launch rate and range checked on the server
- ⚡ **Optimized** — zero loops while the pod is closed

## 🎮 Controls
| Key | Action |
|---|---|
| `B` | Targeting pod on / off |
| `Arrows` | Move the point |
| `Space` | Lock on a vehicle / person |
| `E` | Mark a target |
| `Left click` | Fire / release |
| `Q` | Next weapon |
| `U` | Gray TV / thermal |
| `R` | Reset the point |
| `V` | Weapon camera (Spike / HAROP) |
| `K` | Target coordinates |

## 📦 Requirements
